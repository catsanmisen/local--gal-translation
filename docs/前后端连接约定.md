# 前后端连接约定

2026-10-10。供前端并行修改与后端连接层收尾使用。

## 来源与职责

| 入口 | 布局/样式 | 交互与数据 | 字幕 |
|---|---|---|---|
| 前端独立静态服务 | frontend/ | frontend/js/app.js + mock-api.js；原型模拟 | frontend/subtitle.html；localStorage |
| 实际客户端 /app/ | 只读 frontend/index.html、CSS、SSE 解析器；后端补充样式 | backend/bridge/client.js + api.js；真实 API 和 SQLite | backend/bridge/subtitle.html + subtitle.js；真实字幕状态 |

实际模式的字幕呈现与提示去重共用 `backend/bridge/presentation.js`，它是主窗和独立字幕窗的统一来源。业务/传输修复应用于实际连接层；Mock 修复由前端原型维护。当前保留两个入口，没有把前端原型控制器移走或覆盖。

修改 Mock JavaScript 不会自动修改实际模式。原生字幕、全局热键和 HOOK/OCR 尚未接入，不能只改标签就宣称能力可用。

## 布局协作

后端读取 HTML 时使用 `backend/src/ui_contract.py` 验证必需控件 ID、唯一性和三个原型脚本入口，再替换为实际模式的脚本。版本为 connected-layout-1，通过 `/bootstrap.ui_contract` 返回。

改文案、颜色或间距通常不需要更新该契约。更改控件 ID、移除控件、改变脚本入口或主要控件层级时，需要同步连接层及兼容性测试。检查涵盖必需 ID 和入口，不替代对所有 CSS 结构及交互的浏览器验收。

不兼容时，实际页面返回 UI_LAYOUT_MISMATCH，具体列出缺少或重复的控件；前端文件暂时不可读取时返回 UI_UNAVAILABLE。API 数据与队列继续由后端管理。

## 状态约定

- 流事件带 request_id/session_id/epoch/sequence；只有 final 是完整结果。
- cancelled 的 reason 包含 client_disconnected；计算槽回收超时可附 diagnostic，原始取消原因不改变。
- 重置上下文保留原文历史，术语保存成功才递增版本/epoch。
- 剪贴板错误的 revision 标识事件；CLIPBOARD_BUSY 轻量显示，同一次事件不重复打开横幅。
- 字幕显示模式、字号和底衬透明度必须同时应用于主窗预览与独立预览；文字透明度始终为 1。

## 对接验证

```powershell
python -B -m unittest discover -s backend/tests -v
node backend/tests/test_bridge.cjs
```

浏览器诊断测试可显式运行 `python -B backend/tests/browser_fixture.py`，使用内存数据库、模拟错误和本机 18069；不启动模型，也不读取系统剪贴板。该入口仅用于测试。真实模型联调另行使用 real_smoke.py。
