# 游戏内 Backlog 入口与特殊文字演出布局（2026-10-11）

> 本文保留该轮186项检查与SeaBed短测证据。最新样式、单键隐藏、稳定摆放候选及210项后台检查见 [当前优化与接续](2026-10-14-优先问题后台优化.md)。下文候选、运行状态和额度均指当时，不作为实时状态。

本轮按玩家要求继续上一轮留档、参考《修改参考清单》完善代码，并实现原生游戏字幕的 Backlog / 位置按钮。50句与30分钟正式复验暂缓，Magpie仍不验证。本轮已完成代码、候选构建、186项回归及 SeaBed 短 UI 验证；正式发布目录尚未升级。当前没有要求玩家手动操作的事项。

## 玩家看到的行为

- 字幕右上角新增 **Backlog**，只有主动点击、托盘菜单或 Ctrl+Shift+B 才打开历史。启动、完成翻译、切换字幕位置都不会自动显示历史；阅读历史不回写当前字幕。关闭或 Esc 返回正在玩的台词。
- 同排新增 **位置**，可按游戏保存自动 / 优先上方、下方、左侧、右侧、游戏外侧。提供拖动调整、恢复自动位置、暂时隐藏。设置说明和保存失败原因直接显示在窗口中。
- 字幕正文仍穿透游戏点击，只有小按钮条接收点击。普通鼠标点击按钮不激活字幕窗；自身按钮被辅助功能工具激活时仍保持当前游戏采集状态。默认模式继续排除自身窗口捕获。原生样式保留现有深色界面，补充中文字体与清晰的悬停、禁用状态。
- 长译文先换行并测量，始终限制在安全空隙；文字收起时提示可主动打开 Backlog 查看全文。所有方向都不足时收起正文，再尝试保留小按钮；小按钮也无安全位置时从托盘/快捷键访问。历史不会作为降级窗口自动弹出。

## 特殊文字的摆放设计与实现

`CaptionLayout.cs` 抽离纯物理像素布局，`Overlay.cs` 用真实 WPF 文本测量选择候选空间。按当前显示器工作区夹取，避开任务栏、窗口边框、原文与安全间距；默认间距12 DIP，用户拖动偏移也不能把字幕推入原文保护范围。

| 演出 | 摆放策略 | 边界 |
| --- | --- | --- |
| 底部对话框 | 整块原文上方优先；不足再下方、侧边 | 保留原文可见 |
| 居中标题、分散文字 | 对已检测的完整原文边界避让，按空隙选择上/下/侧边 | 不用最新一行覆盖整个保护范围 |
| 高而窄的文字块 | 右侧、左侧优先，之后上/下 | 按几何形状判断，不声称自动识别所有竖排文字 |
| 累积多行 NVL | 保护本页旧行与新增行的联合边界；游戏内部不足再外侧 | 仍只翻译有效新增部分 |
| 文字铺满客户区 | 尝试窗口外工作区；不足时收起正文 | 最大化/全屏没有剩余工作区时可只保留按钮或全收起 |
| 同一句移动、重排 | 更新本帧边界与位置，保留终态身份和译文 | 不重复调用模型或播放历史 |
| HOOK 未提供屏幕文字边界 | 以玩家保存的区域作为原文保护范围 | HOOK 实机兼容性未在本轮验收 |

OCR只扫描玩家框选区域。演出文字出现在区域外时，需要主动重选区域或改取词方式；当前不会扩大捕获到整个屏幕。布局优先保护原文，不承诺避开所有人物立绘、动画或玩家未标记的装饰区域。可用“优先游戏外侧”进一步减少游戏画面覆盖。

窗口默认使用不激活扩展样式，并响应 WM_MOUSEACTIVATE；工作区来自对应显示器信息。实现依据 Microsoft 的 [扩展窗口样式](https://learn.microsoft.com/en-us/windows/win32/winmsg/extended-window-styles)、[WM_MOUSEACTIVATE](https://learn.microsoft.com/en-us/windows/win32/inputdev/wm-mouseactivate) 与 [GetMonitorInfoW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getmonitorinfow)。负坐标、DPI倍率及部分离屏窗口有逻辑测试，跨屏与实际DPI切换仍须另做实机验证。

## 留档与接续

当前候选和使用方法见 [desktop/README.md](../desktop/README.md)。候选尚依赖项目内运行时、模型与OCR资产，不是完整离线发行包；正式 `desktop/publish/` 未替换。本目录无Git仓库，本轮采用源码快照、统一补丁和SHA256清单，不伪造Git提交。

`work/2026-10-11-overlay-placement/before/` 是本轮动工前基线，`changes.patch`、`changes.zip`、`manifest.json` 保存31个改动文件；上轮 `work/2026-10-11-backlog-fixes/` 保留。`build-hashes.json` 对应候选DLL和关键源码，`quota-checkpoint.json` 仅记百分比及状态。本轮最后归档前读取5小时窗口已用38%、剩余62%，未达到玩家的剩余5%暂停条件；本轮按要求完成后交付。

接续先读实时额度，再读本记录与当前窗口；窗口句号、PID和请求身份只用于本次证据，不保存为游戏恢复配置。当前 SeaBed 日文版停在“瞼がとても重い。”，Backlog/位置设置关闭；客户端使用 `--verification` 供原生观察，普通使用不要添加此参数。

```powershell
$env:DOTNET_CLI_TELEMETRY_OPTOUT='1'
.\.tools\dotnet\dotnet.exe publish desktop/GalTransl.Desktop/GalTransl.Desktop.csproj --no-restore -c Release -o desktop/publish-placement
```
