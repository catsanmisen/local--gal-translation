## 使用当前隔离候选

使用隔离候选验证时指定工作数据库，生产 `data/client.sqlite3` 不改写：

```powershell
cd E:\GalTranslClient
.\desktop\publish-ocr-menu-20261027\GalTransl.Desktop.exe --port 18089 --shutdown
.\desktop\publish-ocr-menu-20261027\GalTransl.Desktop.exe --root E:/GalTranslClient --port 18089 --database E:/GalTranslClient/work/2026-10-27-user-check/native.sqlite3
```

同端口旧候选仍在运行时执行第一条关闭命令，否则直接执行第二条启动新版本，避免只唤起旧窗口或连接旧后端。首次配置从托盘打开游戏设置，选择已启动游戏并框选日文区域；之后正常推进台词。测试用 `--verification` 只为观察原生窗口，会显示任务栏入口并关闭捕获排除；普通使用不要添加该参数。需要保留正常捕获排除并记录OCR路由/桌面接收时刻时，使用 `--diagnostics`；它不会使字幕进入自身OCR。默认不启动剪贴板监听。

桌面设置顶部或浏览器“配置”中的模型设备是全局设置，按“保存并应用设备设置”生效。CPU使用处理器；GPU可按可用显存加载部分层，界面明确显示GPU+CPU及层数。预算不足时保留GPU选择，可等待后续恢复或主动切换CPU；自动模式沿用原兼容策略。GPU显存预留默认2048MiB，1536/1024MiB可给模型更多空间，也会减少游戏余量；CPU下该控件禁用并保留已保存值。运行中修改会安全重载，已完成字幕不重复翻译或写入历史，暂停/退出不会被重载自动恢复。未保存草稿不被轮询覆盖。

同一设置中新增“自动临时停止高占用壁纸”，默认开启，可关闭并保存。提示为“占用显存过大的壁纸可能暂时关闭，翻译结束后自动恢复”；状态显示停止、恢复或失败。高占用Wallpaper Engine可在模型运行期间stop，停止翻译、游戏退出或客户端退出后play，不改原壁纸配置或CPU/GPU选择。10月27日修复宿主提前结束后台清理，真实退出后壁纸租约记录清除、原进程保留；但停止期间仍持有约3.3GB显存，实际释放未通过。GPU/混合中位2秒目标仍保留；游戏短句与整页分别统计，不能将模型耗时冒充端到端延迟。

## 游戏内操作

- 字幕正文穿透，不拦截推进游戏的点击；按钮区的 **Backlog** 仅在玩家点击时显示历史。关闭阅读窗或按 Esc 返回当前台词，记录不会变成实时字幕。新台词不会主动开窗、刷新历史页或滚动到最新。**全文** 只读取当前句快照，不访问历史，可从按钮区、托盘或位置窗打开。
- **位置** 打开摆放设置，可选择自动 / 优先上方、下方、左侧、右侧或游戏外侧，按游戏保存。选择“恢复自动位置”会清除拖动偏移。
- **框选游戏内整个对话框** 保存含空白的对话框范围，优先在框内放译文。它与OCR取词区域分开；原文范围较满或出现框外特殊演出时会安全回退。“清除固定对话框”取消这一范围。
- **单次输入 · 隐藏 / 恢复** 默认关闭。可选左/右/中键、字母、数字、空格、Tab、Esc或F1–F12；按一次隐藏，再按一次恢复。仅当前游戏前台生效，忽略按住重复、组合键、设置窗及Backlog/位置按钮。输入仍交给游戏，因此可能同时推进台词或打开游戏菜单；可选用游戏较少使用的键。
- 默认底衬不透明度为62%，文字保持不透明；已有保存值不强制改写。位置窗口可保存20–100%的不透明度。
- “拖动调整位置”进入编辑，结束可由托盘完成；结束后仍会夹取到安全空隙。位置窗口也提供“暂时隐藏字幕”，用显示快捷键或托盘重新显示。
- 全局默认：Ctrl+Shift+H 显示/隐藏，Ctrl+Shift+P 暂停/恢复，Ctrl+Shift+R 读档重置，Ctrl+Shift+B 主动查看/关闭 Backlog。旧三项配置沿用 Backlog 默认键；注册冲突在设置中提示修改。

## 特殊文字演出

| 原文布局 | 自动摆放 |
| --- | --- |
| 已配置内置对话框 | 优先使用框内安全空隙，并保持仍可用的方向与位置 |
| 底部对话框、普通横排 | 首次上方优先；之后保留安全位置，必要时再换方向 |
| 居中文字、标题或分散文字 | 以已识别原文整体边界避让，上/下空隙均不足再选左右 |
| 高而窄的竖排块 | 优先右/左空隙，保留原文与阅读方向 |
| 累积多行 NVL、满页叙述 | 保护旧行与新行整块边界，尝试游戏外侧的屏幕工作区 |
| 全屏文字、所有安全位置都不足 | 收起字幕正文；小按钮也无安全位置时用托盘/快捷键操作，历史不会自动弹出 |
| 译文较长、当前空隙放不下 | 保持安全锚点，优先选择能放完整译文的备用区；仍不足时通过“全文”主动阅读当前句 |
| 相同原文移动或重新排版 | 跟随更新后的边界，不重复推理、不重播历史 |

外侧字幕避开游戏窗口边框和任务栏；长译文优先使用能显示全文的安全备用区，不默认把省略部分交给Backlog。备用区保持到明确重置、空页或布局变化。没有安全空间时只提供玩家主动打开的当前句全文。所有布局依据已框选区域内的OCR边界，HOOK没有屏幕边界时使用保存区域作为保护范围。

可另存“特殊演出区域”，与常规取词区域分开。常规区连续空约400ms后串行切到备用区，备用期间每秒探测常规区；仍显示的旧页不触发重复提交。该策略不能覆盖常规区旧文字仍在、特殊区同时出现新文字的所有演出，需要后续游戏短测调整；不自动扩大区域或并行翻译两个区域。

保存配置以玩家明确选择的游戏为目标；轮询保留未保存草稿，编辑其他游戏不绑定当前窗口。桌面协议2核对后台根目录和数据库路径，拒绝连接旧协议或其他安装。所属后台持续无响应时可受限重启；非所属服务不会被回收。数据备份、迁移与回退方法见 [后端说明](../backend/README.md#后台身份与数据备份)。
