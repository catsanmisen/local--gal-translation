# GalTranslClient 前端设计说明 v0.1

更新：2026-10-11。对应《docs/前端需求.md》《docs/接口契约-v0.3.md》。
设计方法遵循项目内 skill：`.agents/skills/design-taste-frontend`（taste-skill）。

## 设计解读（Design Read）

面向视觉小说玩家的 Windows 桌面翻译工具，采用冷静克制的工具型语言：原生 CSS 设计令牌 + 系统 CJK 字体 + 低动效。这是工具型产品界面，不是营销页，因此只取 skill 中适用的部分：字体纪律、色彩校准、形状一致性、完整交互状态、反 AI 套路检查。

## 转盘值（Three Dials）

| 转盘 | 值 | 理由 |
|---|---|---|
| DESIGN_VARIANCE | 4 | 工具界面以效率为先，导航轨 + 双栏工作区，不做艺术化错位 |
| MOTION_INTENSITY | 3 | 仅状态过渡与悬停反馈（180-240ms 统一缓动），全部响应 `prefers-reduced-motion` |
| VISUAL_DENSITY | 6 | 状态栏、表格、历史列表需要密度，数字一律等宽字体 |

## 设计令牌（css/tokens.css）

**色彩**：按玩家最新要求使用三种基础色：深灰 `#202226`、中灰 `#494d54`、灰白 `#eeeff1`，层次由透明度、细边框和间距形成。状态保留明确文字与图标，移除绿/黄/红与玫瑰强调色。深 / 浅主题共用这一中性体系，保留手动切换与记忆；游戏画面及系统窗口边框不计为应用基础色。

**字体**：不用 Inter 默认。界面 `Segoe UI` / `Microsoft YaHei UI`，日文原文 `Yu Gothic UI`，数字与元信息 `Cascadia Mono` 等宽。全部系统字体，无 WebFont 加载成本，CJK 渲染稳定。

**圆角**：唯一体系：面板 14px / 控件 10px / 胶囊 999px（文档化规则，全站执行）。

**阴影与材质**：按钮均为圆矩形细边框；字幕使用细顶光、短分隔线与文字阴影，不引入美术图片依赖。默认底衬不透明度由85%降到62%，文字保持完全可见，已有玩家保存值继续生效。web端轻模糊是近似效果，WPF使用透明渐变底衬。

## 界面结构

左侧 76px 导航轨承载五个必做界面（翻译 / 字幕 / 术语表 / 历史 / 配置），顶部状态栏常驻服务状态、显存、模型、会话与启停控制，符合“主窗口必显”要求。翻译页为输入（5fr）与译文流（6fr）双栏；字幕页左预览右控制；术语表与历史用发丝线分行而非层层嵌卡。

## 关键组件决策

- **状态胶囊**：界面中唯一的圆点元素，承载真实引擎状态语义（9 种状态枚举全映射），`loading` 只显示已持续时间，不生成假进度。
- **译文流**：增量文本带光标并标注“翻译中”；`final` 事件整体替换增量缓冲后才标“完成”；截断 / 取消 / 中断各有独立终态标签，原文全程置灰保留在译文上方。
- **风险提示**：warnings 渲染为“需复核”胶囊，悬停看规则原因，不出现置信度或正确率措辞。
- **显存**：状态栏显示 `可用 / 保留阈值 MiB`；低于阈值显示原因横幅与操作入口，不提供绕过手段。
- **空 / 加载 / 错误态**：每个数据区都有空状态构图、形状匹配的骨架屏、内联错误横幅。
- **Mock 调试条**：底部固定，明确标识 mock 场景注入入口，与真实模式区分。

## 反套路自查（taste-skill Pre-Flight 适用项）

- 零 em-dash：可见文案全部使用中文标点或连字符
- 三种中性基础色、单一圆角体系、单一主题方向（深浅为同一主题的两种模式）
- 无渐变文字、无玻璃拟态滥用、无装饰性圆点、无假截图 div
- 按钮文字单行，填充按钮使用 `#494d54` 与灰白文字；原生浮动按钮保持实色，使正文收起后的按钮仍清晰
- 图标统一 Phosphor 一族，无手绘 SVG 图标、无 emoji 图标
- 动效均有语义（状态过渡 / 操作反馈），无无限循环装饰动画

## 后续实现注意

- 正式 WPF / WebView 实现应平移令牌值（颜色、圆角、间距、字体栈），不必平移 CSS。
- 字幕窗在真实实现中是透明置顶窗，mock 中的磨砂底衬近似其视觉效果；字幕不进入自己的 OCR 区域。
- 主题建议跟随系统（`prefers-color-scheme`），保留手动开关。
